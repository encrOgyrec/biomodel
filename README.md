## 📌 Описание проекта
АС «Биомодель» — это десктопное приложение для Windows, предназначенное для моделирования динамики биологических систем «хищник-прей» на основе системы дифференциальных уравнений Лотки–Вольтерры. Вычисления производятся численным методом Эйлера в реальном времени.

### Основной функционал:
* **Интерактивное управление:** Настройка коэффициентов рождаемости, смертности и стартовой численности популяций на левой панели.
* **Два режима визуализации (компонент `Chart`):** 1. Временной тренд (изменение численности видов во времени).
  2. Фазовый портрет системы (эллипсы устойчивости).
* **Автоматическая статистика:** Фоновый расчет математического среднего, экстремумов (минимумы/максимумы) и фиксация времени экологического коллапса (вымирания).
* **Управление симуляцией:** Кнопки «Старт», «Пауза», «Сброс» связанные с обработчиком таймера `Timer1_Tick`.

## ⚙️ Требования к среде и запуск

### Системные требования:
* Операционная система: Windows 10 / 11
* Наличие установленного .NET Framework 4.8+ или .NET Core / 6.0+ (в зависимости от вашей сборки)

### Как запустить проект:
1. Клонируйте репозиторий или распакуйте архив с проектом.
2. Откройте файл решения `Biomodel.sln` в среде **Visual Studio**.
3. Убедитесь, что выбран режим сборки `Release` или `Debug`.
4. Нажмите клавишу **F5** (или кнопку "Пуск" в VS) для компиляции и запуска Windows Forms приложения.

## 📈 Пример использования (Быстрый старт)
1. Запустите приложение.
2. В левой панели параметров оставьте базовые коэффициенты или введите: `Рождаемость жертв = 0.4`, `Смертность хищников = 0.1`.
3. Нажмите кнопку **«Старт»**.
4. Наблюдайте волнообразный график популяционных циклов. При необходимости нажмите **«Пауза»** для фиксации промежуточных данных.
